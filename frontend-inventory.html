1. Vị trí frontend web

apps/desktop — main UI

Tauri + React desktop app · 15,750 LOC · 64 file · phase 6
  • Entry: src/main.tsx → src/App.tsx (god component, 14 routes / 12 pages)
  • Layout dùng @windagent/studio-shell (AppShell, Sidebar, TopBar, MainWorkspace)
  • Pages: Dashboard, Projects, Episodes, Characters, StoryBoard, Reviews, Studio, Production, Agents, Models, Endpoints, Memory, Files, Browser, Settings, Workflows…
  • UI kit riêng: src/components/ui/* (Button, Card, Tabs, Dropdown, Tooltip…)
  • State: zustand (multiAgentStore) + Redux Toolkit cho production packages
  • API: src/api/client.ts, WS: src/services/conversationSocketManager.ts

apps/web — browser build

Vite web app · 39 LOC · re-export thuần của desktop App
  • src/app/App.tsx chỉ re-export @desktop/App qua alias — không có UI riêng
  • Proxy dev: /api → 127.0.0.1:8765, /ws → WS cùng host
  • Port dev: 5173 (strictPort)
  • Suite test rỗng cố ý (passWithNoTests) — test nằm ở apps/desktop

frontend/ — shared packages

npm workspaces monorepo · 10 packages · ~11,700 LOC
  • UI: studio-shell, story-ui, production-ui
  • State: studio-state, production-state
  • API client: studio-client, production-client
  • Contracts (types/route): studio-contracts, production-contracts
  • Platform adapters: production-platform (Tauri / Browser / Fake)

4. Cách chạy

# desktop app (dev)
cd apps/desktop && npm run dev          # Vite dev server

# web app (browser) — cần backend FastAPI ở 127.0.0.1:8765
cd apps/web && npm run dev              # http://localhost:5173

# shared packages — build / typecheck / test toàn bộ
cd frontend && npm run build
cd frontend && npm run typecheck
cd frontend && npm run test

7. Ghi chú kiến trúc

  • Phân lớp 3 tầng: apps (điểm vào) → packages UI (studio-shell / story-ui / production-ui) → packages state/client/contracts (logic + API).
  • apps/web hiện là bản sao mỏng: re-export @desktop/App, không còn UI riêng — legacy web client/state đã bị loại.
  • Backend: FastAPI tại 127.0.0.1:8765; web dev server proxy /api + /ws.
  • Contracts generated: studio-contracts/src/generated/* sinh từ backend spec — không sửa tay.
  • Adapter platform: cùng một production UI chạy được trên Tauri (desktop) và browser nhờ production-platform.
  • Chart WS chưa nối (REST polling) ở appdesktop cũ; studio pipeline dùng HTTP client mới.
