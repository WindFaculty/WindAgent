  sidebarCollapsed: boolean

  conversationId: string  // sessionStorage crypto.randomUUID
  hermesOnline: boolean|null

Pattern: createStore(initializer) → useStore(selector) + getState/setState/subscribe. Health check 10s via apiClient.system.getHealth() trong App.tsx.

query/queryClient.ts • QueryProvider

Lightweight cache (Map<hash, state>) — không phụ thuộc TanStack
QueryClient {
  fetchQuery({queryKey, queryFn, staleTimeMs=5s})
  getQueryState / setQueryData
  invalidateQueries({queryKey?})
  subscribe(key, listener)
  state: {data, error, isLoading, isFetching,
          isSuccess, isError, updatedAt}
}

Đồng thời dùng TanStack Query 5.62 (stale 10s, refetchOnWindowFocus false) trong AppProviders — 2 layers song song.
