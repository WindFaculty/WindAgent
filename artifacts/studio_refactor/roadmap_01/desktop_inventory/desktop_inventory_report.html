Key Findings

  • Studio real (C2-C5). Full story read path: idea → bible → outline → screenplay → review → lock → READY_FOR_PRODUCTION. Redesign = presentation only; no backend/shell changes needed.
  • Production fake-wired. proj-alpha + FakeProductionApiClient + placeholders + hardcoded statuses. Http client exists but unreachable.
  • Hermes badge lies. fetchHermesHealth() returns literal {enabled:false, reachable:false} — can never show connected. 22 v2Unavailable dead-end stubs (agent registry, permissions, pause/resume/retry, task-node editing).
  • Port mismatch. Studio default localhost:8000 vs backend default 8765 — Studio offline unless VITE_API_BASE set (only C7 cert script sets it).
  • No supervisor. sidecar_manager.py orphan (zero callers); backend/worker not bundled in installer, not restarted, orphaned on desktop close.
  • Demo pages. Browser/Files/Memory/Workflows/Endpoints/Settings = hardcoded UI. Sidebar version v1.2.0 vs real 0.3.0; fake user WindUser/Administrator.
  • State patchwork. useState + useReducer (legacy) + Zustand + Context + class store (StudioStore). Redux (production-state) dead export.

Redesign: reuse + extend existing tokens, replace ad-hoc styling.
